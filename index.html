Reproducibility¶

The repository stores self-contained JSON benchmark logs under data/lambda_json_logs. The command make figures regenerates manuscript figures from those logs. The Docker workflow can rerun the full benchmark suite on an NVIDIA GPU and produce fresh JSON logs.

Funding¶

The archived benchmark logs were produced on Lambda.ai/Lambda Labs GPU infrastructure. The broader project has also been supported by the Google Cloud Research Award number GCP19980904.
